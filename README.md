\# Unit 3 AI Lab Experiments



This repository contains five Python experiments covering embeddings,

vector databases, Retrieval-Augmented Generation (RAG), domain-specific

chatbots, and document-based AI assistants.



\## Experiments



\### Experiment 1 — Text Embeddings and Semantic Similarity

Generates text embeddings using Sentence Transformers and compares

the semantic similarity between sentences.



\### Experiment 2 — Vector Database

Creates a vector database using ChromaDB and performs semantic search

over stored documents.



\### Experiment 3 — Document Question Answering using RAG

Loads a PDF document, retrieves relevant information, and uses an

LLM through OpenRouter to generate an answer based on the retrieved

document context.



\### Experiment 4 — Domain-Specific Chatbot

Builds a domain-specific Artificial Intelligence chatbot using

LangChain and ChromaDB.



\### Experiment 5 — AI Assistant using External Documents

Loads an external PDF document and retrieves relevant information

to answer user questions.
